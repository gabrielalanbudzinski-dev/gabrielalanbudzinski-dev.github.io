# Gabriel Budzinski — Portfolio

Static portfolio website ready for free hosting.

## Files
- `index.html` — main portfolio
- `style.css` — visual design and responsive layout
- `script.js` — scroll reveal animation
- `assets/profile.jpg` — profile photo

## Before publishing
1. Email and LinkedIn are already set (gabriel.alan.budzinski@gmail.com / linkedin.com/in/gabriel-budzinski).
2. Optionally replace/add project artwork in the `.case-media` sections.

## Publish for free
### GitHub Pages
Create a GitHub repository, upload these files, then enable Pages in:
Settings → Pages → Deploy from branch → `main` / root.

### Vercel
Import the GitHub repository into Vercel. No build command is required.

The site is plain HTML/CSS/JS, so there is no framework or build step.
